# Solid and Linked Data

Slides for a presentation on **Solid and Linked Data**, given at CERN on 13 March 2023.

The presentation provides an introduction to Linked Data and the Solid ecosystem, covering the ideas behind decentralized personal data stores, RDF-based data interoperability, identity, access control, and the state of the Solid ecosystem at the time of the presentation.
